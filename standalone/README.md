# Standalone skills

Agent skills for Terraform and OpenTofu that work in any repository and need no StackGuardian account. Install them with the [skills CLI](https://github.com/vercel-labs/skills) or the Claude Code plugin; the [README](../README.md#skills-that-work-with-any-repo) has the commands.

The `tirith-*` folders are copies of the skills in [StackGuardian/tirith](https://github.com/StackGuardian/tirith), pinned to the tag in `TIRITH_VERSION`. Do not edit them here: change them in Tirith, bump the tag and run `node scripts/sync-tirith-skills.mjs`.
